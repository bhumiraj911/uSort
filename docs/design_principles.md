# uSort Design Principles

## Philosophy

uSort should feel modern, calm, and trustworthy.

The interface should guide the user instead of overwhelming them.

---

## Core Principles

### 1. One Window, Multiple States

The application should never open unnecessary windows.

The interface changes as the workflow progresses.

---

### 2. Motion Has Purpose

Animations should communicate progress.

Never animate just for decoration.

---

### 3. Progressive Disclosure

Only show information when it becomes relevant.

Don't overwhelm users with every option at once.

---

### 4. User Is Always In Control

Never modify files without confirmation.

Always provide a preview before organizing.

---

### 5. Safety First

Default to the safest behavior whenever possible.

---

### 6. Simplicity Over Complexity

If two designs solve the same problem,

choose the simpler one.

---

### 7. Consistency

Buttons, cards, spacing and animations should behave consistently throughout the application.

---

## Animation Rules

✓ Card shrink

✓ Section expansion

✓ Progress bar

✗ Fancy animations

✗ Unnecessary effects

✗ Long transitions

Animations should be subtle and fast.

Target duration:
200–300 ms
