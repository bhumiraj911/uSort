# uSort Product Notes

> Organize memories, not folders.

---

# Vision

uSort helps people organize thousands of photos and videos safely, intelligently, and beautifully.

---

# Target Users

- Families
- Photographers
- Travelers
- Students
- Anyone with thousands of photos/videos

---

# Product Principles

1. Safety First
2. User Always Has Control
3. No File Is Modified Without Confirmation
4. Fast
5. Beautiful UI
6. Easy To Use
7. Scalable

---

# Feature Ideas

## 001 - Folder Tree Builder

Status: Planned

Description:

Users can decide how folders are created.

Examples:

Year
└── Month

Year
└── Month
    └── Day

Year
└── Month
    └── File Type

File Type
└── Year
    └── Month

Future:
Drag-and-drop to reorder levels.

Reason:

Every user organizes memories differently.
uSort should adapt to the user instead of forcing one structure.

---

# Product Rules

- Never move files automatically.
- Always preview before organizing.
- Copy should be the default action.
- Every destructive action requires confirmation.
- Every operation should be reversible whenever possible.
